## 1. 系统总览

### 1.1 硬件组成与接线

**硬件**：
- **心电模拟前端板**（自建）：TL062 仪表放大 + LMV358 有源滤波 + LMV324 导联判决/右腿驱动；Uref = 1.65V 中点偏置；AC 耦合；输出 ECG / LEAD_OFF 为模拟量（板上无 MCU）；
- **主控**：立创·天空星 STM32F407VET6（Cortex-M4F @168MHz）；
- **下载器**：ST-Link（SWD 模式）；
- **串口**：USB-TTL（CH340，115200）；
- **信号源**：心电信号模拟器（RA/LA/RL 三端子，支持 60/120/150/240bpm 等档位）。

**关键连线**：

| 从 | 到 | 说明 |
|---|---|---|
| 心电板 ECG 输出 | 天空星 **PA5**（板载丝印 A05） | ADC1_IN5，主信号 |
| 心电板 LEAD_OFF 输出 | 天空星 **PA1**（板载丝印 A01） | ADC2_IN1，导联脱落信号 |
| 两板 GND | 互联 | 必须共地 |
| ST-Link SWDIO/SWCLK/GND | PA13 / PA14 / GND | 烧录与调试 |
| USART1 PA9/PA10 | USB-TTL | 波形数据 |

### 1.2 数据流架构

```
心电模拟器 → 心电板(放大/滤波/右腿驱动) → [PA5]
                                              │
┌──────────────── STM32F407（500Hz 主链）─────┴───────────────────────┐
│ ①TIM2 500Hz TRGO 触发 → ②ADC1(PA5)转换 → ③DMA 搬运 → s_arrADC1Data │
│ → ④TIM2中断: 入队(256环形队列) + OVR自愈 + DMA搬运计数              │
│ → ⑤主循环 ProcWaveData(每2ms): 消费样本                             │
│ → ⑥滤波链(bias→50Hz陷波→40Hz FIR) → s_filtDataLast                  │
│ → ⑦心率检测(逐样本) → s_heartBpm                                    │
│ → ⑧导联检测(ADC2 独立采样 PA1) → s_leadOff                          │
│ → ⑨维包输出 VofaWaveTick(每2样本/250Hz): sprintf 4通道              │
│ → ⑩WriteUART1 队列(256B) → TXE中断 → 串口 115200 → PC(VOFA)         │
└──────────────────────────────────────────────────────────────────────┘
辅助: Proc1SecTask 每秒一行状态; PrintBootInfo 上电自检
```

## 2. 运行逻辑（代码旅程）

### 2.1 上电初始化顺序（`main()`）

```c
InitSoftware();   // ecg_filt_init → ecg_heart_init → ecg_leadoff_init → 协议模块
InitHardware();   // RCC → NVIC → SysTick → UART1 → Timer → LED → ADC
PrintBootInfo();  // 自检信息
while(1) { Proc2msTask(); Proc1SecTask(); }
```

`InitADC()` 内部顺序（**修复后**，不可随意调换）：
**配DMA并使能 → 使能ADC → 最后启动TIM2**。
原因：TIM2 一启动就发触发脉冲，ADC/DMA 未就绪时请求会丢失。

### 2.2 采样链（每 2ms）

1. TIM2 更新事件 → 硬件 TRGO 触发 ADC1 转换（PA5，480 周期采样，约 23µs）；
2. 转换完成 → DMA2_Stream0 搬运到 `s_arrADC1Data`（volatile）；
3. `TIM2_IRQHandler`：入队 + 清 OVR（计数）+ 清 TCIF（DMA 计数）。

### 2.3 主循环消费与处理（`ProcWaveData`，每 2ms）

```c
while((pointCnt < 8) && ReadADCBuf(&adcData)) {
    s_filtDataLast = ecg_filt_step(&s_ecgFilter, (float)adcData);  // 滤波
    s_heartBpm     = ecg_heart_step(&s_heartDet, s_filtDataLast);  // 心率
    s_leadOff      = ecg_leadoff_step(&s_leadDet);                 // 导联
    if(s_leadOff) s_heartBpm = 0;                                  // 脱落→心率无效
    VofaWaveTick(adcData, s_filtDataLast);                         // 每2样本发一帧
}
```

### 2.4 滤波链（逐样本）

```
原始码值 − 2048(1.65V中点) → 50Hz陷波 → 40Hz FIR低通 → 输出
```
- 陷波（DF2T biquad 三行递推）：`y=b0x+s1; s1=b1x+s2−a1y; s2=b2x−a2y;`
- FIR：361 抽头、环形缓冲、从最新往最老累加；群延迟 180 样本（360ms，恒定）。

### 2.5 心率检测（逐样本，状态机）

1. 滑窗极值：最近 2048 样本按 64/块分块，环形存 32 块极值；
2. 门限：`thr = min + 0.6×(max−min)`；
3. R 峰：过阈→跟踪候选峰（记峰值与"最后创新高"位置）→回落 3 样本确认→不应期 100 样本（0.2s）；
4. 心率：RR 环形缓冲（8 个）→中位数→`bpm = 30000 / 中位RR`；
5. 保护：窗峰峰值<150 判信号丢失（清 RR、输出 0）；上电 2 秒才启用输出。

### 2.6 导联脱落（逐样本）

- ADC2 软件触发单次转换读 PA1（约 23µs，与 ADC1 主链完全独立）；
- 码值 > 2000 计数 +1、≤2000 计数 −1；满 50（100ms）判脱落；
- EOC 等待带超时保护，防卡死。

### 2.7 串口输出

- `VofaWaveTick`（每 2 样本 = 250Hz）：
  `sprintf(line, "%u,%d,%d,%d\n", 原始值, 滤波值, 心率, 导联状态)` → `WriteUART1`（入队，非阻塞）；
- TXE 中断后台逐字节发送；整个链路仅一个入队者（主循环）一个出队者（中断）。

## 4. 踩坑档案（现象 → 定位 → 修复）

### 4.1 F4 ADC+DMA "只搬运一次"（DDS 位陷阱）★最关键

- **现象**：串口数据流持续但数值冻结；复位后恢复一次又冻结；接线变化不跟随。
- **定位**：加"探针"——TIM2 中断里清 DMA 的 TCIF 标志并计数（`dmacnt`）。实测 72 秒只搬了 **1** 次 → 锁定在 DMA/ADC 搬运链。
- **根因**：F4 的 ADC_CR2 的 **DDS 位**默认 0——"最后一次 DMA 传输结束后不再产生 DMA 请求"；本工程 DMA 目标为单变量、BufferSize=1，**第一次搬运即构成 last transfer**。官方 SPL 源码注释证实。
- **修复**：`ADC_DMARequestAfterLastTransferCmd(ADC1, ENABLE);`（配 ADC_DMACmd 之后）。
- **教训**：数据流在跑 ≠ 数据在更新；给关键链路装"行为计数探针"是最快的破案手段。

### 4.2 串口数据流乱码（两处竞争）

- **现象**：偶发/成段的畸形数据行（4 段数字、缺字符、超长数字）。
- **根因 1**：1s 状态行用 `printf` **直写串口寄存器**，与 TXE 中断的队列发送在 DR 寄存器上以字节为单位竞争；
- **根因 2**：环形队列计数器在主循环（写）与中断（读）间**无临界区**，非原子自增/自减偶发差 1，导致字节流整段错位。
- **修复**：①状态行改 `sprintf`+`WriteUART1` 走同一队列（全程唯一写者）；②`WriteUART1`/`ReadUART1` 的队列访问加 `__disable_irq()/__enable_irq()` 临界区。

### 4.3 心率不应期三次演进（被实测数据逼出来的）

| 版本 | 不应期 | 实测现象 | 结论 |
|---|---|---|---|
| v1 | 250 样本(0.5s) | 120bpm 显示 **80**（RR=250 与不应期撞车 + 3 样本确认延迟 → 周期性丢峰 → RR 交替 250/500 → 中位 375 → 80） | 下调 |
| v2 | 150 样本(0.3s) | 150bpm 显示 150 ✓，但 240bpm 测不到 | 继续下调 |
| v3 | **100 样本(0.2s)** | 60/120/150/240 全中（误差 0%） | 达标 |

配套修复：不应期从"峰位置"起算（扣除确认延迟）；T 波由 0.6 门限兜底。

### 4.4 其他修复与防御（简表）

| 项 | 内容 |
|---|---|
| 初始化顺序 | InitADC: DMA→ADC→TIM2 |
| OVR 自愈 | TIM2 中断检测到 ADC 溢出即清并计数（常备防御） |
| volatile | `s_arrADC1Data` 由 DMA 后台写入，必须 volatile |

## 5. VOFA 使用与验收演示

**VOFA+ 设置**：协议 FireWater、115200、数据引擎 FireWater；
**四通道**：ch0=原始码值、ch1=滤波值、ch2=心率bpm、ch3=导联状态(0/1)；
**显示建议**：Δt 改 4ms（数据实际 4ms/帧）；Y 轴手动固定（ch0: 0~4095；ch1: -500~1000；ch2: 0~250）。

**验收演示流程（建议顺序）**：
1. 开场：模拟器 60bpm，四通道全显示——"采集/滤波/心率/导联一体"；
2. 工频滤除：指着 ch0（脏）vs ch1（干净）讲解陷波+低通；
3. 心率：模拟器依次切 120 → 240bpm，界面跟随；
4. 导联脱落：拔一根电极 → ch3 跳 1、ch2 清零 → 插回恢复；
5. 数据素材：滚动截屏 VOFA 数据流（≥1000 点/参数）。

## 8. 常用操作速查

**改滤波参数（如截止频率/陷波开关）**：
1. 改 `EcgMcuSim/ecg_config.m`（或 `EcgMcuC/ecg_config.h` 对应项）；
2. MATLAB 跑 `EcgMcuC/gen_ecg_coeffs.m` 重新生成系数；
3. 把新 `ecg_coeffs.h/.c` 拷贝到工程 `Alg/`（**注意转 GBK 编码**）；
4. Rebuild + 烧录。

**编译烧录**：Keil 打开 `project\MDK(V5)\Project.uvprojx` → Rebuild → Download（ST-Link，SWD）。

**代码文件约定**：工程侧文件为 **GBK 编码**（Keil 中文显示）；`EcgMcuC/` 侧为 UTF-8；修改工程文件时先备份。

**回归测试清单（改任何算法后）**：
- 60bpm：心率 60、波形正常；
- 240bpm：心率 240；
- 拔线：导联跳 1 + 心率清零；插回恢复；
- 数据流无畸形行（串口无乱码）。
